# AI-Based ECG Arrhythmia Detection System

## Overview

This project detects different types of cardiac arrhythmias using Deep Learning.

## Features

- Upload ECG image
- AI-based prediction
- Normal / Abnormal detection
- Confidence score
- Disease description
- Symptoms
- Clinical recommendation
- Patient record storage using SQLite

## Technologies Used

- Python
- Streamlit
- TensorFlow
- OpenCV
- NumPy
- SQLite
- Matplotlib

## Dataset

MIT-BIH Arrhythmia Dataset

## Model

CNN + CBAM Deep Learning Model

## Run

```bash
streamlit run streamlit_app/app.py
```
